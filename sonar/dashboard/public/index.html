Como usar

  1. ./sonar/scripts/up.sh — sobe SonarQube (Docker) + este portal
  2. Primeiro acesso em localhost:9000: login admin / admin e troque a senha
  3. ./sonar/scripts/scan.sh — analisa o código e publica no Sonar
  4. Recarregue esta página para ver Quality Gate, vulnerabilidades e smells

Segredos (ex.: COURTESY_SEED_KEY) devem ficar só em variáveis de ambiente / Secret Manager — nunca no git. Análise completa de Swift requer SonarQube Developer Edition ou SonarCloud; a Community analisa Functions (TS), rules e Docs.
