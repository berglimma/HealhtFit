APP PURPOSE & AUDIENCE
HealthFit is a fitness companion for adults 16+ who want guided workouts, nutrition planning, and optional AI coaching. It helps users train (strength, cardio, sports), track wellness, and optionally subscribe for tiered premium features.

EXTERNAL SERVICES
- Firebase (Auth, Firestore, Cloud Functions, FCM, Storage)
- Apple Sign In, Google Sign In
- Apple HealthKit, CoreLocation (active sessions), CoreMotion
- StoreKit 2 (subscriptions)
- No third-party ads or cross-app tracking

REGIONAL DIFFERENCES
Same feature set in all App Store territories. UI localized in pt-BR (primary), en-US, es-ES, fr-FR.

SANDBOX SUBSCRIPTION TEST (optional)
After login: Profile → Meu plano → choose a plan → purchase with Sandbox Apple ID.
Restore: Profile → Meu plano → Restaurar compras.
Core workouts (Básico+) unlock after subscribing. Nutrition/IA features require Fit or IA Plus tiers.

IAP SUMMARY (where to buy)
Profile → Meu plano → choose tier (Básico / Fit / IA Plus / Completo) → Monthly or Yearly → purchase.
Restore: Profile → Meu plano → Restaurar compras.
Courtesy codes (30-day grant, not IAP): Profile → Meu plano → Tenho um código de cortesia.

ALTERNATIVE: Create account in-app
1) Tap Criar conta (email + password), OR
2) Use Sign in with Apple.
Minimum age: 16+.

HOW TO TEST CORE FLOWS
1. Onboarding → complete profile (gender, goal, modalities).
2. Workouts tab → guided strength (Básico+) OR Cardio → Corrida / Luta (Fit+ for advanced modalities).
3. Nutrition tab → meal plan + shopping list (Fit+). Meal photo Análise (IA Plus).
4. Assistant tab → ask a question (Fit: 5 msgs/day; IA Plus: unlimited).
5. Workouts → Dupla/equipe → create/join team → chat (long-press to Report).
6. Profile → Meu plano → subscribe / Restore purchases.
7. Profile → Excluir conta (Guideline 5.1.1(v)).
