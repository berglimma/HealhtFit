HealthFit — App Review Notes (v1.0.0)

BUNDLE
- iOS: luan.com.healthfit.app
- watchOS: luan.com.healthfit.app.watchkitapp
- Version 1.0.0 / Build 1

DEMO ACCOUNT
No pre-seeded account required. On the review device:
1) Tap Criar conta (email + password), OR
2) Use Sign in with Apple.
Complete the short profile prompts, then use the flows below.
Minimum age: 16+. If the review team prefers a fixed account, contact berg.limma@gmail.com and we will provide credentials within a few hours.

HOW TO TEST CORE FLOWS
1. Onboarding → complete profile (gender, goal, modalities).
2. Workouts tab → start a guided strength workout OR Cardio → Corrida / Luta.
3. Nutrition tab → view meal plan; shopping list via cart icon; Análise for meal photo (IA Plus feature).
4. Assistant tab → ask a simple question (e.g. “Como melhorar meu sono?”).
5. Workouts → Dupla/equipe → create/join team → chat (long-press a message to Report; leave team from hub).
6. Profile → Meu plano → Restore purchases / view subscription tiers.
7. Profile → Excluir conta is available (Guideline 5.1.1(v)).

HEALTHKIT / LOCATION / MOTION
- HealthKit: metrics and workout sync (user must grant permission).
- Location: used for outdoor cardio/sports maps (run/walk/bike/surf/kite). Background location only while an active outdoor session is tracking; purpose strings explain Always if requested by the system for continuous tracking.
- Motion: pedometer / activity state / climbing motion assist.
- No third-party advertising; no cross-app tracking.

USER-GENERATED CONTENT (DUO CHAT)
- Private team chat to coordinate workouts only (no public feed).
- Messages expire (~12 hours).
- Users can report a message (mailto support) and leave the team.
- Contact for moderation: berg.limma@gmail.com

CONTENT DISCLAIMER
HealthFit provides informational fitness and nutrition guidance only. It does not provide medical diagnosis or replace a licensed professional.

WATCH APP
Companion app for live heart rate / calories / session control. Pair Apple Watch with the same Apple ID for best results. Review can be completed on iPhone alone.
