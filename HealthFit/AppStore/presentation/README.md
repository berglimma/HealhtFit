# Apresentação de vendas HealthFit

## Abrir

Abra no navegador (Chrome, Safari ou Edge):

```
AppStore/presentation/HealthFit-Vendas.html
```

Atalho a partir da pasta do repositório:

```bash
open HealthFit/AppStore/presentation/HealthFit-Vendas.html
```

Apresentação comercial completa (deck longo):

```bash
open Docs/HealthFit_Apresentacao_Comercial.html
```

## Novas funções destacadas na apresentação

- **Dupla / equipe** — chat 12h, ranking, badges de não lidas, sem GPS ao vivo  
- **GPS de corrida reforçado** — rota estável com tela bloqueada e pinos início/fim  
- **Refeições próprias** — biblioteca do usuário + recomendações do catálogo  
- **Dia de descanso** — IAssistente com orientação de recuperação  
- **Sync Firebase** — conta, foto de perfil e planos na nuvem  
- **Surf e Kitesurf** — SPOT, vento e maré, mapa GPS 2D/3D, saltos, diário  
- **Calendário do iPhone** — treino concluído vira evento no dia  
- **PDF e Galeria** — compartilhar relatórios e salvar cards/fotos  
- **StoreKit 2 + vouchers** — assinaturas App Store e cortesia  
- Outdoor completo (rua + água) no mesmo app

## Exportar para PDF / PPT

1. Abrir o HTML em tela cheia (`F` / zoom 100%).  
2. Capturar cada slide ou usar extensão “Print to PDF” (1 página por slide).  
3. Ou importar os GIFs/PNGs no Keynote montando os títulos deste roteiro.
