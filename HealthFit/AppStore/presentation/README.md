# Apresentação de vendas HealthFit

## Abrir

Abra no navegador (Chrome, Safari ou Edge):

```
AppStore/presentation/HealthFit-Vendas.html
```

Atalho a partir da pasta do repositório:

```bash
open AppStore/presentation/HealthFit-Vendas.html
```

## Controles

| Ação | Como |
|------|------|
| Avançar | `→` · Espaço · botão Próximo · swipe esquerdo |
| Voltar | `←` · botão Anterior · swipe direito |
| Ir ao slide | clicar nos pontos inferiores |

## Conteúdo (15 páginas)

1. Capa — mundo **HealthFit** (GIF)
2. Problema do mercado  
3. Solução / ecossistema  
4. Personal trainer digital  
5. Nutrição / cardápio  
6. IAssistente  
7. GIFs e demos de exercício  
8. Apple Watch + Saúde  
9. Outdoor (corrida, caminhada, bike)  
10. Progresso e relatórios  
11. Diferenciais  
12. Planos de assinatura  
13. Público-alvo  
14. Resumo de benefícios  
15. **Finale** — GIFs animados de personal + nutricionista + mundo HealthFit  

## Mídia em `media/`

- `mundo-healthfit.gif` — globo com marca HealthFit  
- `personal-trainer.gif` — personal animado  
- `nutricionista.gif` — nutricionista animada  
- PNGs de origem em alta resolução para export (Keynote/Canva)

## Exportar para PDF / PPT

1. Abrir o HTML em tela cheia (`F` / zoom 100%).  
2. Capturar cada slide ou usar extensão “Print to PDF” (1 página por slide).  
3. Ou importar os GIFs/PNGs no Keynote montando os 15 títulos deste roteiro.
