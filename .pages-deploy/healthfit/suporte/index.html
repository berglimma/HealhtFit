Assinaturas

  • Comprar ou mudar de plano: no app, Perfil → Meu plano.
  • Restaurar compras: Perfil → Meu plano → Restaurar compras.
  • Cancelar: Ajustes do iPhone → [seu nome] → Assinaturas → HealthFit.

Exclusão de conta

No app: Perfil → Excluir conta. Isso remove dados da conta conforme a Política de Privacidade.

Problemas comuns

  • Apple Health / Watch: conceda permissões em Ajustes → Saúde → Apps → HealthFit e no Watch.
  • Localização (corrida/bike/surf): Ajustes → Privacidade → Localização → HealthFit → Ao Usar.
  • Login com Apple: use o mesmo Apple ID com o qual criou a conta.
